- **A value a bar on pattern methods:** `.fast`, `.slow`, `.add`, `.sub`, `.ply` and `.degrade` take a quoted value a bar, as in Strudel: `.add("<0 3 5>")` transposes by 0, 3 and 5 in turn, and a nested `< >` takes its own turns, so `.add("<0 <1 -1>>")` is 0, 1, 0, −1. The method prints as written; on a live clip `.add` and `.sub` follow the song's bar (#629).
