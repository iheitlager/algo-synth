- **Scale progressions:** `.scale(<a1 d2>/4 minor-pentatonic)` takes up to 16 roots in turn, a bar each or `/n` bars each, `a1:dorian` with its own mode; each note takes the key of the bar it starts in, so Strudel's `n("<0 2 1 3 2>*8").scale("<A1 D2>/4:minor:pentatonic")` is one clip. A note clip may now run 64 bars (#571).
